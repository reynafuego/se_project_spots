# Spots

An interactive image-sharing application where users are able to add/remove photos, like photos, and make minor adjustments to their profile.

## Description

This project introduces responsive design, where your webpage adapts to different screen sizes. You'll use tools like CSS Grid, media queries, and other techniques to create a layout that looks great on desktop, tablet, and mobile devices.

## Tech Stack

-HTML
-CSS
-Responsive Design
